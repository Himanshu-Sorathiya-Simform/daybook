- Prisma's schema language cannot declare check constraints or RLS.
- Route handlers lack the origin checks Server Actions get.
- Postgres runs foreign-key checks with the table owner's rights and skips RLS for them. So the runtime role needs no grant on the auth user table, and a single-column foreign key could link to another user's row (hence D-193). The RLS suite confirms both at M0.
- Better Auth's internal context (`auth.$context`) exposes its password hasher and an internal adapter that can update a credential, for the developer reset script (F01, BR-F01-28). Better Auth stores each session's user agent.
- Have I Been Pwned's range API takes the first 5 hex characters of a SHA-1 hash, returns matching suffixes, needs no key, and supports the `Add-Padding` header.
- Postgres 15 and later support `ON DELETE SET NULL (column_list)`; Neon runs Postgres 15 or later.
- Drizzle's node-postgres driver applies its own parsing per column mode, so P2 states outcomes rather than global parser settings.
- Sanity Live's browser connection goes to `<projectId>.api.sanity.io`, which P2's CSP allows through `*.api.sanity.io` (confirmed by the M7 review against next-sanity 13's source).
- Deleting a Stripe Customer cancels its active subscriptions immediately.
- NIST SP 800-63B advises against password composition rules.
- Badging API support: Chromium desktop installed apps, Safari web apps on macOS, iOS home-screen apps after notification permission.
- Running migrations over Neon's direct endpoint; per-request round-trip cost to a cloud region.
- Stripe test clocks for renewal, failure and lapse scenarios; PWA installability on localhost.
- ECharts' LTTB sampling (`sampling: 'lttb'`) on line series.
- Postgres accepts every `zone.tab` name and every `backward` link in `AT TIME ZONE`. AC-F02-04 checks the list.
- `new Intl.Locale('en').maximize()` gives region US; `Intl.DateTimeFormat` with `en-<region>` falls back to plain `en` formatting where ICU has no data for that region.
- A UUIDv7 built from a row's `createdAt` and generator bits is valid and unique across users, because the seed includes the user id.
- date-fns `addMonths(start, k)` keeps the start's day of month and clamps it to the target month's last day, so computing every due date from the start gives TIME-9's anchored schedule (F05, AC-F05-01 checks it).
- A multiplicative random walk with daily mean return μ and standard deviation σ grows along its median path at about μ − σ²/2 a day. This gives F07's per-type growth figures, and showed that the first crypto parameters (+400 and 40,000 ppm) fell about 25% over two years.
- Postgres's `round(numeric)` rounds half away from zero. `INSERT ... ON CONFLICT DO UPDATE ... WHERE` writes nothing and returns no row from `RETURNING` when the condition is false (F08's layout upsert). A concurrent insert on the same unique key waits for the first transaction, then does nothing if it committed or inserts if it rolled back (P2's daily-pass marker).
- node-postgres runs one query at a time per client, so the statements of one transaction each cost a round trip (D-293, D-294).
- ECharts needs `MarkPointComponent` for `markPoint` on a series, and a `visualMap` of type `piecewise` takes explicit `pieces` with `min` and `max` (F09's trade markers and heat-map levels).
- Nearest-rank percentile: the value at rank ⌈p × n⌉ of the ascending list. For golden 2026's 17 positive days, ranks 5, 9 and 13 give 649.00, 1,850.00 and 3,200.00 (F09).
- Stripe keeps active entitlements while a subscription is `past_due`, since it revokes them on cancellation, including cancellation after failed payments. This is inferred, not stated; AC-F12-15 checks it.
- Stripe expands at most four levels deep, so a Price's `currency_options` cannot be read through a subscription list (F12, BR-F12-10).
- Stripe idempotency keys can be pruned 24 hours after first use, so a retry inside that window replays the first answer (F12, BR-F12-05).
- Stripe retries a sandbox webhook delivery to a registered endpoint three times over a few hours, against up to 3 days in live mode (D-308). Forwarding through `stripe listen` is not documented to redeliver, so F12 relies on the lazy billing check.
- Next.js `after()` runs work after the response is sent, in route handlers (F12's lazy check, D-310).
- The Web Locks API is available in service workers as well as pages, so one lock name serializes the page runner and Background Sync (P1, BR-P1-17).
- Chromium fires a `sync` event at once when it is registered online, ends it when its `waitUntil` promise settles, and retries only a rejected one. It allows a `sync` handler minutes, not seconds, so waiting out a 5-second hold fits (P1, BR-P1-27). Scripts a page loaded before its service worker took control bypass the worker, but are listed in `performance.getEntriesByType('resource')` (P1, BR-P1-06).
- `navigator.storage.persist()` is granted or refused by the browser's own rules (engagement, installation, a prompt in some browsers); asking again changes nothing (P1, BR-P1-28).
- Safari deletes a site's script-writable storage after 7 days of browser use without visiting it, unless the site is installed as a web app (P1, section 13).
- TanStack Query's dehydrate options include `shouldDehydrateQuery`, which picks the queries a persister saves (P1, BR-P1-11).
- Next.js RSC requests carry `RSC: 1` and an `_rsc` parameter, and their responses vary on the router-state headers, so a cached payload matches only the exact router state it was fetched from; P1 caches documents instead (D-363).
- Constructing or forwarding a navigation request from a service worker cannot replace a check the server makes, so the offline-logout revocation is done by `proxy.ts` from a cookie (D-367).
- From the M7 review, which read the published package sources (next-sanity 13.3.4, @sentry/nextjs and @sentry/core 11.8.0). Re-check at M7:
    - next-sanity 13 requires Next.js 16 and React 19.2. `defineLive` comes from `next-sanity/live`; without tokens it reads published documents only.
    - `<SanityLive>`'s default `action` is a Server Action that revalidates tags; `action="refresh"` calls the client router's refresh instead (F14, D-378).
    - Sentry 11 replaced `sendDefaultPii` with `dataCollection`, whose defaults collect user info, cookies, headers, bodies and query parameters. Spans are filtered in `beforeSendSpan` (P3, D-380).
    - Drizzle 0.44 and later wrap driver errors in `DrizzleQueryError`, which carries the SQL and its parameters (P3, D-381).
- From the second M7 review and its follow-up check, which read next-sanity 13.3.4, @sanity/client 7.27.0 (next-sanity 13.3.4 depends on ^7.26.2), next 16.4.2, @sentry/* 11.8.0, drizzle-orm 0.44.7 and lighthouse 13.5.0. Re-check at M7:
    - **next-sanity `sanityFetch`:** with `cacheComponents` off, it first fetches sync tags uncached, then reads with `next: { revalidate: false, tags }`, which Next.js keeps in the Data Cache until a tag is revalidated. A segment's `fetchCache = 'force-no-store'` overrides that (F14, D-378).
    - **next-sanity's Server Action:** its `react-server` entry imports `revalidateSyncTagsAction` whatever `action` is passed, so the build registers that action even though nothing calls it (AC-F14-11).
    - **`<SanityLive>` after `goaway`:** it falls back to refreshing every 30 seconds. `onGoAway={false}` turns that off and reports the event through `onError`, which logs to the console by default (D-385).
    - **`<SanityLive action="refresh">`:** it calls `router.refresh()` on every message event, whatever its tags.
    - **`fetchCache`:** Next.js applies a segment's `fetchCache` only while that segment renders. A soft navigation renders only the page, so a layout's setting does not cover its pages' fetches. `force-no-store` overrides `revalidate: false`, and also works in route handlers (D-378).
    - **@sanity/client:** its default `timeout` is 300,000 ms, with retries; `timeout` and `maxRetries` are client options (D-385).
    - **Sentry 11's `dataCollection`:** it also has `databaseQueryData`, `stackFrameVariables`, `genAI`, `graphQL`, `queues` and `frameContextLines`. `genAI` and `graphQL` are objects (`{ inputs, outputs }` and `{ document, variables }`), so `false` leaves them on.
    - **Sentry's automatic capture:** `onRequestError` builds the event from the raw error. For a `DrizzleQueryError` that message is `Failed query: …` followed by the parameters, and the linked-errors integration adds its `cause` (P3, BR-P3-05).
    - **Sentry 11's `traceLifecycle`:** it defaults to `'stream'`, and `beforeSendSpan` then receives streamed span JSON (D-380).
    - **Sentry's element selectors:** UI breadcrumbs and INP span names use `htmlTreeAsString`, which appends an element's `aria-label`, `title`, `name` and `alt` (P3, BR-P3-04).
    - **Sentry's tunnel:** `tunnelRoute` is a Next.js rewrite to `o<org>.ingest.sentry.io/api/<project>/envelope/` for any numeric organization and project. The browser transport accepts `fetchOptions`, so `credentials: 'omit'` keeps cookies off it (BR-P3-01).
    - **The proxy's runtime:** `proxy.ts` runs on the Node.js runtime in Next.js 16, so Sentry needs no edge initialization (D-354).
    - **Bundle measure:** a `next/dynamic` import is listed in the build's loadable manifest, under Turbopack too (P3, BR-P3-09).
    - **Lighthouse:** `disableStorageReset` keeps cookies and the service worker between runs (D-379).
- Node.js 24 enters maintenance on 2026-10-20, and Node.js 26 becomes Active LTS on 2026-10-28, per the nodejs/Release schedule (P3, D-359).
- Dependabot pull requests receive no repository secrets, so a job needing `SONAR_TOKEN` is skipped for them (P3).
- Workbox-style cache-first strategies store only status 200 by default. Opaque cross-origin images need `crossorigin` (F14), or a cacheable-response rule (P1).
- Playwright's `setExtraHTTPHeaders` adds headers to every request of a context. F11 adds its token header to the document request only, through `page.route`.
- Next.js's `notFound()` sets a 404 when it runs before any streaming, so F11's print page decides its status with no Suspense above the check.
